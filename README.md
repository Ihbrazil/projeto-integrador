# projeto-integrador
 Projeto Integrador - ReactJS Aplicação desenvolvida na disciplina de Projeto Integrador, utilizando ReactJS para o desenvolvimento de uma interface moderna e responsiva. Funcionalidades: CRUD completo para gerenciamento de dados. Autenticação de usuários. Rotas públicas e privadas. Controle de acesso para usuários e administradores. Tratamento de erros e estados de carregamento. Reutilização de componentes e serviços. Tecnologias ReactJS. Tailwind CSS. React Router. JavaScript. Objetivo: Aplicar conceitos de desenvolvimento Front-end, incluindo componentização, estilização, gerenciamento de rotas, autenticação e boas práticas de desenvolvimento com ReactJS.
